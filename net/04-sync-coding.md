## метод скремблирования

(смешивание)

передатчик a_i -> скремблер (S) -> b_i -> дескреблер (DS) -> c_i -> приемник

где a_i = c_i


b_i = a_i xor b_(i-3) xor b_(i-5)

_обратные связи_

c_i = b_i xor b_(i-3) xor b_(i-5)

НЕ ПУТАЕМ b!

> произвольную послть преобразовать

b_0 = a_0 = 1
b_1 = a_1 = 1
b_2 = a_2 = 1
b_3 = a_3 xor b_0 = 0
b_4 = a_4 xor b_1 = 0
b_5 = a_5 xor b_2 xor b_0 = 1 xor 1 xor 1 = 1
