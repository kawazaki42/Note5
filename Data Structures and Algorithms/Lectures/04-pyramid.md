# пирамидальная сортировка

для массива

1. преобразовать массив в пирамиду
2. удалить корень пирамиды, добавить его в начало нового массива
3. повторять пункт 2 пока в пирамиде есть элементы

сложность по времени: O(n log n)

почему?

массив из n элементов преобразуется в дерево с log_2 n уровнями

вставка в пирамиду - log_2 n, удаление тоже

этих операций у нас n

отсюда n log n
