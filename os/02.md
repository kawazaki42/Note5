ос по типу ядра:
- монолитное
  - одна большая программа
  - работает максимально быстро
  - но стабильность ниже (см. kernel panic)
  - сложность модернизации
  - как таковых сейчас такие не выпускают
    - MS-DOS например
- микроядро
  - ядерные компоненты вынесены в прикладной уровень
  - есть отдельное МИКРОядро
  - такую систему модернизировать легче
  - MINIX, QNX
- модульное
  - монолитное, но собирается из отдельных модулей
  - Linux, другие UNIX-подобные ос
- гибридное
  - windows, macacos
  - микроядро в ядерном режиме (не пользовательском)
  - набор монолитных модулей в ядерном режиме

режимы работы процессора:
- пользовательский
  - недоступны некоторые машинные инструкции
  - нет прямого доступа к аппаратным ресурсам в тч. всей памяти
- ядерный

0 и 3 кольца (0 - привелигированный)

справка: в x86 есть аж 4 кольца, но используются только крайние

условия перехода в ядро:
- системные вызовы  (trap)
  - syscall
    - помогает восстанавливать контекст
    - доступна в x86-64
  - svc
  - аппаратные прерывания
- аппаратные прерывания (interrupt)
  - асинхронное событие
- исключения (exceptions, faults)
  - генерируются самим процессором
